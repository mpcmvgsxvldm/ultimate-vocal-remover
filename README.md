## Overview

Ultimate Vocal Remover is a desktop application that uses state-of-the-art AI models — VR Architecture, MDX-Net, and Demucs — to separate music tracks into vocals, drums, bass, and other stems. It runs fully offline with GPU acceleration and is the leading free stem separation tool for producers and karaoke enthusiasts alike.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Ultimate Vocal Remover** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multiple AI Models** | VR Architecture, MDX-Net, and Demucs models for best-fit separation |
| **Multi-Stem Output** | Separate into vocals, drums, bass, other, and instrumental stems |
| **GPU Accelerated** | CUDA GPU acceleration for fast offline stem separation processing |
| **Batch Processing** | Process entire music libraries through the model queue in one run |
